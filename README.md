# Expense Tracker

A ReactJS web app to record, categorize and monitor income and expenses.

## Features
- Add, edit and delete income and expense transactions
- Categories, dates and notes
- Summary of income, expenses and balance
- Filter by month, type, or search text
- Spending-by-category donut chart and 6-month income/expense bar chart (plain SVG, no chart library)
- Monthly budgets per category with progress bars and over-budget warnings
- Export the current view as CSV
- Data stays in your browser (localStorage)

## Run on Windows
1. Install Node.js (LTS) from https://nodejs.org
2. Open the project folder in VS Code, then open a terminal (Ctrl + `)
3. Run:

```
npm install
npm run dev
```

4. Open the link shown in the terminal (usually http://localhost:5173)

## Build
```
npm run build
```
